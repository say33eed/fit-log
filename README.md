# FitLog — Workout Library

FitLog is a responsive workout library and planning application where users can explore workouts, view exercise details, build today's workout plan, log workouts, and save workouts for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js App Router
- React Hot Toast
- Lucide React
- Local Storage

## 5 Key Features

1. **Workout Library** — Browse all workouts from the FitLog API with images, muscle groups, equipment, duration, calories, and ratings.

2. **Workout Details** — View detailed workout information including equipment, difficulty, sets, reps, duration, calories, rating, and exercise instructions.

3. **Today's Plan** — Add up to five workouts to today's plan, view live exercise/minute/calorie totals, mark workouts as done, and remove workouts.

4. **Saved Workouts** — Save workouts for later and manage them from the Saved tab on the My Plan page.

5. **Persistent & Responsive Experience** — Plan and Saved data persist using localStorage, while the application is fully responsive across mobile, tablet, and desktop screens.
